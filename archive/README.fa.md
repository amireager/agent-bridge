# آرشیو پروژه

اسناد این پوشه برای حفظ تاریخچه و تصمیم‌های قدیمی نگه‌داری می‌شوند؛ مرجع اجرای امروز نیستند.

- `NOTES-early-design.md`: یادداشت‌های مرحلهٔ طراحی اولیه؛ شامل فرضیه‌ها و معماری‌هایی که لزوماً با محصول فعلی سازگار نیستند.

قواعد روز در `../PROJECT_RULES.md` و جهت حرکت محصول در `../GOALS.md` ثبت می‌شود. اگر یادداشت آرشیوی با این فایل‌ها یا کد فعلی تعارض داشت، مرجع جاری اولویت دارد.
