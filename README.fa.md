# Agent Bridge — آینه‌ی زنده، مترجم و آزمایشگاه مدل محلی

[English README](README.md)

`agent-bridge` یک لایه‌ی سبک و محلی میان ابزارهای چتی مانند `pi` و `llama-server` است. هدف اصلی، ساخت یک مترجم کاربردی برای کاربران فارسی‌زبان و ابزارهای سنجش مدل است؛ نه ساخت یک پوسته‌ی پرزرق‌وبرق دیگر برای چت.

## قابلیت‌ها

- ترجمه‌ی مسیر درخواست از فارسی به انگلیسی، همراه با حفظ بلوک‌های کد و قالب Markdown.
- آینه‌ی زنده‌ی درخواست‌ها و پاسخ‌های ترمینال (`pi`, `pi-2` و کانال‌های دیگر)؛ هر ترمینال کانال خودش را دارد.
- چت مستقیم داخلی برای آزمایش مدل محلی، جدا از آینه‌ی ترمینال.
- ثبت آمار توکن، نرخ کش KV، سرعت prompt/decode، و هزینه‌ی فرضی بر اساس چند پروفایل قیمت.
- تنظیمات مترجم آنلاین یا API آفلاین دلخواه با URL و پورت انتخابی کاربر.
- داده‌ها و تنظیمات runtime فقط در مسیر محلی `./.data/` ذخیره می‌شوند.

## اجرا

ابتدا `llama-server` را روی loopback اجرا کن؛ نمونه‌ی رایج در NixOS:

```fish
ai-serve ~/models/minicpm5-2b-heretic-q5_k_m.gguf \
  -fa on -ctk q8_0 -ctv q4_0 -c 98304 -ub 256 \
  --temp 0.6 --top-p 0.95
```

سپس در ترمینال دیگری:

```fish
cd ~/agent-bridge
python3 bridge.py --host 127.0.0.1 --port 18080 --upstream http://127.0.0.1:8080
```

مرورگر: `http://127.0.0.1:18080/`

## آینه‌ی ترمینال pi

برای اتصال یک ترمینال:

```fish
cd ~/agent-bridge
python3 cli.py --wrap pi
```

برای نام‌گذاری دستی کانال دوم:

```fish
python3 cli.py --wrap pi --name pi-2
```

در wrapper، `Ctrl+C` اول به برنامه‌ی فرزند می‌رسد. برای خروج اجباری از wrapper، `Ctrl+C` را بار دوم ظرف حدود ۱٫۴ ثانیه بزن؛ خروج، گروه فرزند را می‌بندد و ترمینال را بازمی‌گرداند. سرور Bridge فرایند جداگانه‌ای است و با بستن هر ترمینال بسته نمی‌شود؛ برای توقف آن، در ترمینال خودش `Ctrl+C` بزن.

## مترجم آفلاین دلخواه

در Settings می‌توان Online یا Custom Offline را انتخاب کرد. حالت OpenAI-compatible از `POST /v1/chat/completions` استفاده می‌کند. حالت REST از این قرارداد بهره می‌برد:

درخواست:

```json
{"text":"Text to translate","from":"en","to":"fa"}
```

پاسخ:

```json
{"translation":"ترجمه"}
```

URL و پورت را خود کاربر تعیین می‌کند؛ موتور خاصی به‌اجبار نصب یا اجرا نمی‌شود.

## امنیت و دامنه

- سرور مدل را روی `127.0.0.1` نگه دار و پورت آن را بدون حفاظت روی اینترنت منتشر نکن.
- ابزارهای shell در چت داخلی محلی اجرا می‌شوند؛ فقط وقتی فعالشان کن که به مدل و فرمان‌های تولیدشده اعتماد داری.
- Bridge یک مترجم/پراکسی و داشبورد محلی است؛ نباید با کنترل‌گر ترمینال یا agent مستقل اشتباه گرفته شود.
